# SPA-Cache: Singular Proxies for Adaptive Caching in Diffusion Language Models

- authors: Wenhao Sun, Rong-Cheng Tu, Yifu Ding, Zhao Jin, Jingyi Liao, Yongcheng Jing, Dacheng Tao
- venue: arXiv preprint
- year: 2026 (submitted 2026-01-30)
- url: https://arxiv.org/abs/2602.02544
- tags: [dllm-cache, per-layer-position-refresh, refresh-only, singular-proxy, **closest-prior-art**]

## Key claims

- **First per-(layer × position) refresh-only caching for dLLM** (very close to our H004 / Phase 12 framing).
- Uses a low-dim **"singular proxy"** = top-r SVD truncation of the Value projection matrix W_v (r=128 from d=4096).
- Per-layer different active set: each layer l independently picks Top-k tokens with lowest cosine similarity between current proxy and cached proxy from previous step.
- Per-layer adaptive budget ρ(l).
- **Recompute-only** for selected tokens — "complexity scales with k rather than total N for both Attention and FFN".
- Throughput: up to 8× over vanilla, 2-4× over existing caching baselines.

## Method

1. Offline: SVD on W_v_l per layer, keep top-r singular vectors → proxy projection W_r_l ∈ R^(r×d).
2. At each step, for each layer l (sequential):
   - Compute proxy p_i = W_r_l · h_i for each position (input to layer l).
   - Compare cosine similarity to cached proxy from previous step.
   - Select Top-k positions with lowest similarity → refresh set A_l.
   - Run layer l forward on A_l only (skip compute for rest).
   - Update proxy cache.

## Why it matters here

**This is the closest prior art to our Phase 12-14 work.** Same paradigm
(refresh-only per (layer × position)), same granularity, same general idea
that the active set is sparse per layer. Concurrent (Jan 2026, ours starting
~May 2026).

Distinctions to defend our contribution:

| dimension | SPA-Cache | Ours (Phase 12-14) |
|---|---|---|
| signal type | Value-space cosine similarity (direction) via SVD proxy | Lag-1 hidden-state delta norm (magnitude) |
| signal compute | per-layer projection + cosine compare (O(rd) per token per layer per step) | zero compute — purely from cached snapshots |
| signal lag | lag-0 (compares current proxy to cached) | lag-1 (uses prev-step's delta to predict this step) |
| inductive bias | none (learned via SVD on W_v) | structural: U_t + window4 included by default |
| explanation | "drifts in hidden states" (descriptive) | cascade containment under bidir attention (mechanistic via R26 + Phase 12) |
| sparsity numbers | up to 8× throughput, 2-4× over caching baselines | oracle ceiling K/T=0.10 → 10× attn ceiling; lag-1 K/T=0.28 → 3.5× ceiling |
| accuracy story | "negligible impact" claimed (need exact numbers) | GSM8K + HumanEval baseline-parity verified |

Our remaining novelty (provisional):
1. **Mechanistic story**: R26 negative result + Phase 12 cascade containment positive → answers WHY refresh-only works for bidir attention. SPA-Cache likely doesn't have this diagnosis.
2. **Simpler signal**: pure history (lag-1) vs learned proxy (SVD). Easier to deploy, no offline calibration. But possibly less accurate.
3. **Structural inductive bias**: explicit U_t + window incorporation, not learned.
